# Linux Keylogger (Educational Project)

A low-level Linux keylogger written in C, designed to demonstrate interacting with system devices, handling system calls, and reading hardware input events.

> **Disclaimer:** This project was developed strictly for educational purposes to learn about Linux internals, C programming, and system calls. It must not be used for malicious purposes or on systems without explicit authorization.

## Prerequisites

- **OS:** Linux (Kernel 2.6+)
- **Compiler:** GCC
- **Permissions:** Root / `sudo` access (required to read from `/dev/input/` devices)
